# OTP King Telegram Bot

Telegram bot (`otp-king-bot`) for OTP King's virtual and temporary number service. Users can request numbers, share referrals, and admins can manage the bot from Telegram. Data is stored in Firebase.

## Features

- Virtual / temporary number requests
- Referral program
- Admin controls
- Firebase-backed data

## Stack

Python / Node Telegram bot, Firebase

This repository is a public showcase of the OTP King Telegram bot.
